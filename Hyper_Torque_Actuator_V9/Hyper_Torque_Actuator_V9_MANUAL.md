### Introduction

The Hyper Torque Actuator V9 (Mechanical) is a high-performance, compact actuator designed for industrial applications that require precise control and high torque output. This manual provides essential information on the assembly, installation, operation, and maintenance of the actuator.

### Specifications

| Parameter | Value |
| --- | --- |
| Torque Output | 100 Nm (73 lb-ft) |
| Speed Range | 0 - 300 RPM |
| Power Input | 24V DC or 12V DC |
| Current Consumption | 10A (max) |
| Dimensions | 120mm x 80mm x 60mm (4.7" x 3.1" x 2.4") |

### Assembly and Installation

#### Pre-Installation Checks

* Ensure the actuator is properly packaged and free from damage.
* Verify that all components are included in the package.

#### Step-by-Step Assembly Instructions

1. Mount the actuator to a stable surface using the provided mounting bracket.
2. Connect the power input wires to the actuator's terminals.
3. Install the gear box and motor assembly according to the manufacturer's instructions.
4. Secure all components with the recommended fasteners.

#### Installation Considerations

* Ensure proper ventilation around the actuator to prevent overheating.
* Keep the actuator away from moisture and water sources.

### Operation and Maintenance

#### Operating Modes

The Hyper Torque Actuator V9 (Mechanical) can operate in two modes:

1. **Position Control**: The actuator moves to a specific position based on the input signal.
2. **Speed Control**: The actuator maintains a constant speed based on the input signal.

#### Maintenance Schedule

* Regularly inspect the actuator for signs of wear or damage.
* Clean the actuator's components with compressed air and a soft brush.
* Lubricate moving parts according to the manufacturer's instructions.

### Troubleshooting

| Issue | Possible Cause | Solution |
| --- | --- | --- |
| Actuator not responding | Power input issue | Check power supply and connections. |
| Actuator vibrating excessively | Misaligned or loose components | Realign or tighten components as necessary. |
| Actuator overheating | Insufficient ventilation | Improve ventilation around the actuator. |
