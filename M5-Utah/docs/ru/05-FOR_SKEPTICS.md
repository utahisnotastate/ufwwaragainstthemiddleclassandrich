# Руководство M5-Utah для скептиков

Вы правы, задавая жёсткие вопросы. Эта страница отвечает на них прямо — без жаргона хронологий.

---

## Краткий ответ

**Этот репозиторий содержит две разные вещи:**

1. **Творческий/научно-фантастический архив** (27 «оружий UFW», экономическая сатира, лор хронологий) с кодом-заглушкой, ссылающимся на вымышленные библиотеки.
2. **Небольшой реальный встроенный проект** (`M5-Utah/`), который прошивает платы ESP32 и запускает **обычные демо**: датчики, ШИМ, звук, жесты, радиопакеты.

Второе **не** доказывает экстраординарные утверждения первого.

## Что на самом деле реально?

| Утверждение в маркетинге/лore | Что оборудование реально делает |
|-------------------------------|----------------------------------|
| «Zero Point GPU — infinite FPS» | 2D-симуляция волн + отрисовка на LCD на ESP32-S3 |
| «Infinite Akashic RAM» | Счётчик событий ступенчатых площадок по I2C |

| «Med-bed heals DNA» | ~61.8 Hz синус + инвертированное реле — **демо звуковой электроники** |
| «Print anything you imagine» | Жест запускает счётчик шагов мотора + мигание УФ-реле |
| «God-eye war room» | Датчик расстояния переключает состояние; широковещательные пакеты ESP-NOW |
| «JIT bytecode into PSRAM» | **Вводящее в заблуждение название** — предкомпилированные C++-обработчики, выбираемые JSON-манифестом |
| «Eliminate the stock market» | **Политический/сатирический нарратив** в корневом README — не функция ПО |

Если кто-то говорит, что этот репозиторий сам по себе опровергает экономику или физику, **это не подтверждается кодом.**

## Что можно проверить за один день?

С ~$50–200 деталей M5Stack и ноутбуком:

1. `py -3 run_studio.py --list` — шесть манифестов существуют; магия не нужна.
2. Прошить ядро → инъекция манифеста → **увидеть и измерить поведение** (список в [Каталоге артефактов](ARTIFACTS.md)).
3. Осциллограф на выходе PAA → **прямоугольная волна 7.83 Hz** — да, действительно эта частота; нет, не «скалярная психотронная энергия».
4. Наступить на FSR → **строка serial-лога** — воспроизводимо.
5. Прочитать `firmware/M5IntegratedKernel/src/artifacts/*.cpp` — **всё поведение там в простом C++**, без скрытых сетевых вызовов к «Akashic cloud».

**Опровержение:** Если инъекция манифеста не даёт serial ACK и изменения UI, конвейер сломался — это обычная инженерная отладка, а не секретность.

## Красные флаги (в любом форке или продаже)

| Красный флаг | Проверка реальности |
|--------------|---------------------|
| «No soldering» продаётся как «нарушает термодинамику» | Беспаечная сборка — **удобство**, не новая физика |
| Оценки уверенности вроде 0.94 в JSON/MD | **Назначены автором**, не рецензирование журналом |
| Цитаты в SCIENCE.md, не соответствующие эксперименту | Читайте связанные статьи — они часто не поддерживают смелое утверждение |
| Заглушки вроде `#include <zpe_core.h>` | **Заголовки не существуют** — никогда не было компилируемым fantasy API |
| «Works best if you believe» | Вера — не вход датчика в `flux_common.py` |
| Готовый .bin без исходников | Требуйте соответствующий хеш коммита + SHA-256; исходники в этом репозитории |

## Ответы на частые возражения

### «Это мошенничество?»

Репозиторий — **открытый исходный нарратив + открытая прошивка**. Никому не нужно платить, чтобы читать код. Риск — в **наценке на железо** или **ложных медицинских обещаниях**, если третья сторона перепродаёт платы — оценивайте продавца, а не GPIO.

### «Это опасно?»

**Катушка + внешний БП** и **громкие излучатели** могут быть небезопасны при неправильной проводке. Путь для скептика: низкое напряжение, ограничение тока, защита слуха. **Не используйте артефакт med-bed как медицинское лечение.**

### «Зачем письмо General 23 / NYSE?»

Сатира и мифология проекта в `README.md`. Это не регуляторная подача. **Развёртываемая инженерия** живёт в `M5-Utah/`.

### «Говорят JIT injection — это фейк?»

**Частично вводящая в заблуждение терминология.** Настоящий JIT компилирует в runtime (например, LLVM, Java bytecode). Здесь **JSON-манифест выбирает среди предкомпилированных модулей артефактов**, прошитых внутри ядра. Всё ещё полезный UX; не новая компьютерная наука.

### «Можно работать без интернета?»

**Да.** Инструменты хоста и прошивка работают офлайн. Облако не требуется в `M5-Utah/`.

## Честные сильные стороны (дать должное)

1. **Модульное сопоставление M5Stack** — разумный BOM для обучения (PbHub, FSR, DAC, gesture).
2. **UX одной прошивки и многих режимов** — законное улучшение workflow мейкера.
3. **Чёткий serial-протокол** — проверяем в `flux_protocol.cpp`.
4. **Возможно разделение** — можно форкнуть `M5-Utah/` без одобрения экономических утверждений UFW.
5. **Доступна детская рамка** — см. [Для детей](01-FOR_CHILDREN.md) с явными пометками «не настоящая med-bed».

---

## Честные слабости

1. **Перегрузка названиями** — экстраординарная лексика на обычных встроенных задачах сбивает с толку покупателей.
2. **Родительские заглушки** — 27 проектов всё ещё импортируют фейковые Python/C++ модули.
3. **Оценки уверенности SCIENCE.md** — могут подразумевать валидацию там, где её не было.
4. **Worker swarm не завершён** — workers Command Table ESP-NOW нуждаются в отдельной прошивке, не полностью поставленной.
5. **Нет подписанных манифестов** — инъекция доверительная по serial; крипто-аутентификации пока нет.

## Протокол репликации для скептика (минимальная стоимость)

**Бюджетный путь:** только CoreS3 (~$50) + USB-кабель.

```
git clone <repo>
cd M5-Utah
py -3 -m pip install -r requirements.txt
py -3 run_studio.py --list                    # verify manifests
# After build or obtaining .bin:
py -3 run_omni_flash.py
py -3 run_studio.py --artifact zero_point_gpu
```

**Критерий успеха:** Serial выводит `ACK: ARTIFACT_ACTIVE`; дисплей анимируется.  
**Критерий неудачи:** Нет ACK → документируйте порт, драйвер, несоответствие board env — публикуйте отрицательный результат.

## Как взаимодействовать конструктивно

| Делайте | Не делайте |
|---------|------------|
| Измеряйте частоты, счётчики I2C, задержки | Опровергайте соломенного «infinite GPU», не читая `zero_point_gpu.cpp` |
| Просите хеши манифеста + прошивки | Требуйте доказательства телепатии от счётчика шагов |
| Форкните и честно переименуйте артефакты | Смешивайте сатиру корневого README с инженерией M5-Utah |
| Сообщайте о проблемах воспроизводимости как GitHub issues | Предполагайте злой умысел, когда проблема — драйверы CP210x |
