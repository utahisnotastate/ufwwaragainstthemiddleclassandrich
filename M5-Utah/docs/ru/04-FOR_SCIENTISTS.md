# Руководство M5-Utah для учёных и исследователей

Этот документ разделяет **проверяемое поведение оборудования** и **нарративные физические утверждения** в архиве UFW и предоставляет воспроизводимые протоколы измерений для шести развёртываемых артефактов.

---

## Краткое резюме

| Слой | Характер | Статус рецензирования |
|------|----------|----------------------|
| Прошивка M5-Utah и инструменты хоста | Встроенные системы + Python serial-инструменты | Стандартная инженерия; воспроизводимо при наличии оборудования |
| Родительские файлы `*_SCIENCE.md` | Смешанная экспозиция с оценками уверенности | Не независимая валидация; трактуйте как авторский нарратив |
| Термины лора (ZPE, Akashic memory, med-bed healing) | Спекулятивная / вымышленная рамка | **Нет доказательной базы** в этом репозитории |

**Что можно публиковать:** инструментальная характеристика GPIO, I2C, PWM, акустики и поведения ESP-NOW.  
**Что нельзя утверждать только на основе этого репозитория:** биологическая регенерация, извлечение вакуумной энергии, печать материи из мыслей или психотронная причинность.

## Таксономия утверждений

### Уровень A — Напрямую измеримо (World-A)

- UART-инъекция манифеста на 115200 baud с заданным фреймингом
- Двухзадачное выполнение FreeRTOS на ESP32-S3
- Аналоговые чтения I2C с PbHub + делители напряжения FSR
- ШИМ-прямоугольные волны на 7.83 Hz и 40.0 Hz
- Генерация синуса I2C DAC ~61.8 Hz с инверсией фазы реле
- Прерывание жеста через чтение регистров PAJ7620U2 по I2C
- Пороги расстояния VL53L0X time-of-flight
- Широковещательные кадры ESP-NOW на радио Wi-Fi 2.4 GHz

### Уровень B — Аналогии с опубликованной физикой (требуют вашей собственной цепочки цитирования)

- **Резонанс Шумана (~7.83 Hz):** Крайне низкочастотная электромагнитная модa полости Земля–ионосфера. **Электрический осциллятор** 7.83 Hz на столе не эквивалентен связи с этим геофизическим режимом без анализа антенны, напряжённости поля и SNR.
- **40 Hz gamma entrainment:** Опубликованная нейронаучная литература рассматривает парадигмы 40 Hz сенсорной стимуляции; **это устройство не демонстрирует клинических исходов**.
- **61.8 Hz акустическая интерференция:** Подавление биений и инверсия фазы — классическая акустика; отображение на «эффект Priore» или «фазово-сопряжённую биологию» — **гипотеза**, не продемонстрированная здесь.
- **Волновое уравнение на 2D-сетке:** Численный шаблон лапласиана в `zero_point_gpu.cpp` — стандартная конечно-разностная демонстрация, не вакуумные вычисления.

### Уровень C — Не имеет эмпирической основы в кодовой базе

- Zero-point energy GPU / Casimir compute
- Akashic / vacuum memory allocation
- Клеточная регрессия возраста
- Голографическая компиляция материи из намерения
- Психотронное скалярное вещание
- Аналитика хронологий / обнаружение враждебности

## Протоколы по артефактам

### 1. Zero Point GPU Emulator

**Гипотеза (проверяемая):** Ядро 0 вычисляет обновление 2D скалярного поля, пока ядро 1 рендерит, не голодая UI-цикл.

**Аппаратура:** CoreS3, USB serial, опционально логический анализатор на UART TX.

**Процедура:**

1. Инъекция `Zero_Point_GPU.flux.json`.
2. Лог serial на 115200 в течение 60 с.
3. Захват обновления дисплея визуально или камерой с известным FPS.
4. Опционально прочитайте `parameters.grid_size`, `wave_speed`, `zpe_gain` из манифеста и сопоставьте с визуальной скоростью распространения.

**Наблюдаемые величины:** Счётчик кадров в serial (`ZPE GPU f=N`); стабильное обновление дисплея; без watchdog reset.

**Не продемонстрировано:** Извлечение вакуумной энергии, проекция фотонного hard-light.

---

### 2. Mnemonic DDR Infinity

**Гипотеза (проверяемая):** Давление FSR снижает аналоговый счёт ниже `strike_threshold` и вызывает события с debounce.

**Аппаратура:** Core2, PbHub, 4× FSR, мультиметр опционально на каналах hub.

**Процедура:**

1. Инъекция манифеста; отметьте `strike_threshold` (по умолчанию 1800).
2. Приложите известные массы к FSR-площадкам; логируйте serial-события `[DDR] Memory write`.
3. Постройте кривую числа срабатываний vs. приложенной силы.

**Наблюдаемые величины:** Монотонный рост `write_count`; ID канала в логе.

**Не продемонстрировано:** Нелокальная память, петабайтное выделение, блокировка пространства-времени.

---

### 3. Psychotronic Amplifier Array

**Гипотеза (проверяемая):** AtomS3 выводит стабильную низкочастотную прямоугольную волну на GPIO затвора MOSFET.

**Аппаратура:** AtomS3, MOSFET Unit, осциллограф на затворе и клеммах катушки, **внешний БП с ограничением тока**.

**Процедура:**

1. Инъекция манифеста; по умолчанию `schumann` → 7.83 Hz.
2. Измерьте период T ≈ 127.7 ms ± бюджет допуска (кристалл, джitter `delayMicroseconds`).
3. Нажмите BtnA; проверьте переключение на ~40 Hz (T ≈ 25 ms).
4. Задокументируйте скважность vs. параметр `duty_percent`.

**Безопасность:** Не пропускайте высокий ток катушки через GPIO; MOSFET изолирует MCU.

**Не продемонстрировано:** Обнаружение психотронного сигнала, связь разум–материя; ссылки arXiv/MDPI в родительском SCIENCE.md **не воспроизведены** этой прошивкой.

---

### 4. Cellular Regenesis Chamber

**Гипотеза (проверяемая):** DAC выводит синус на `carrier_hz`; выход реле логически инвертирован на полупериод.

**Аппаратура:** CoreS3, Unit-DAC, Unit-Relay, два излучателя или высокоомные зонды осциллографа, SPL-метр опционально.

**Процедура:**

1. Инъекция манифеста (`carrier_hz`: 61.8).
2. Захват аналогового выхода DAC — ожидайте синус с f ≈ 61.8 Hz.
3. Захват цифрового выхода реле — ожидайте фазовое соотношение 180° к нулевым пересечениям синуса (с учётом задержки реле).
4. Если установлен акустический тракт, измерьте SPL; **используйте безопасные для слуха уровни**.

**Не продемонстрировано:** Ресеквенирование ДНК, восстановление теломер, снижение энтропии в биологической ткани.

---

### 5. Holographic Printing Press V5

**Гипотеза (проверяемая):** Код жеста PAJ7620 `0x04` вызывает инкремент Z и импульс реле длительностью `uv_pulse_ms`.

**Аппаратура:** Core2, Unit-Gesture, Unit-Relay, осциллограф на контактах реле.

**Процедура:**

1. Инъекция манифеста.
2. Выполните контролируемый свайп вниз на фиксированном расстоянии; считайте импульсы реле.
3. Проверьте, что `z_position_steps` увеличивается на 800 за срабатывание (константа прошивки).

**Не продемонстрировано:** Конвейер отверждения SLA-смолы, материализация вакуумного напряжения, метрики ясности намерения.

---

### 6. UFW Tactical Command Table

**Гипотеза (проверяемая):** Дальность VL53L0X ниже `wave_threshold_mm` переключает состояние системы и испускает пакеты ESP-NOW.

**Аппаратура:** CoreS3, Unit-ToF, второй ESP32 как ESP-NOW sniffer (опционально), анализатор спектра Wi-Fi опционально.

**Процедура:**

1. Инъекция манифеста.
2. Приближайте руку на измеренных расстояниях; логируйте переходы HALT/ACTIVE.
3. Захватите кадры ESP-NOW sniffer'ом; задокументируйте широковещательный MAC `FF:FF:FF:FF:FF:FF` и структуру полезной нагрузки `WorkerPacket` (см. `war_room.cpp`).

**Не продемонстрировано:** Классификация враждебного намерения, симуляция хронологий, FinOps-сенсинг прибыльности.

## Связь с родительскими файлами `*_SCIENCE.md`

Пример: `Psychotronic_Amplifier_Array_SCIENCE.md` сообщает уверенность 0.94 с уравнениями формы Шрёдингера и внешними цитатами. **Эта оценка внутренняя для схемы архива**, а не результат слепого реплицирования.

Рекомендуемая интерпретация:

1. Используйте SCIENCE.md как **концептуальную библиографию и заметки гипотез**.
2. Используйте прошивку M5-Utah как **определение аппарата** только для измерений уровня A.
3. Не объединяйте утверждения уровня C с результатами уровня A без отдельных пререгистрированных исследований.

## Этические и безопасностные заметки для исследований с людьми

- **Без медицинских утверждений** — артефакт med-bed является аудио/электронным стендом.
- **Защита слуха** при длительном воздействии 61.8 Hz или 40 Hz на высоком SPL.
- **Эксперименты с катушкой** — ограничивайте ток; риск возгорания при непрерывном переключении MOSFET в индуктивную нагрузку.
- **ESP-NOW / Wi-Fi** — RF-воздействие в пределах потребительских устройств; документируйте местные нормы.
