# Глоссарий

Простые определения терминов, используемых в M5-Utah и более широком архиве UFW.

| Термин | Значение |
|--------|----------|
| **Artifact** | Режим устройства — например, контроллер ступенчатых площадок, дисплей волн, жестовый принтер. Выбирается в `studio.py`. |
| **Blueprint** | JSON-файл в родительском репозитории, описывающий концептуальные компоненты артефакта (`*_BLUEPRINT.json`). |
| **ESP32** | Микроконтроллер внутри устройств M5Stack. Запускает прошивку ядра. |
| **Flux manifest** | Файл `.flux.json`, сообщающий устройству, какой артефакт запускать и с какими настройками. |
| **FSR** | Force Sensitive Resistor — площадка, чувствующая наступание. |
| **Grove cable** | Цветной разъёмный кабель модулей M5Stack (без пайки). |
| **I2C** | Двухпроводная шина для связи с модулями (PbHub, DAC, датчики). |
| **JIT injection** | Отправка манифеста по USB, чтобы устройство сменило режим без перепрошивки. |
| **Kernel / Lazarus Kernel** | `M5IntegratedKernel` — базовая прошивка, прошиваемая один раз; принимает манифесты после. |
| **Manifest** | То же, что Flux manifest. |
| **M5Stack** | Бренд модульных ESP32-гаджетов (экраны, датчики, стекируемые модули). |
| **Omni-Flash** | `omni_flash.py` — инструмент, прошивающий ядро на пустой M5Stack. |
| **PbHub** | Модуль M5Stack, считывающий до 6 аналоговых датчиков по I2C. |
| **PSRAM** | Дополнительная RAM на некоторых платах ESP32 для больших буферов. |
| **Sovereign Node** | Название в проекте для M5Stack, работающего с Lazarus Kernel. |
| **Studio / Utah Flux Host** | `studio.py` — инструмент, перечисляющий и инъектирующий манифесты. |
| **UFW** | Utah Future Weapons — семейное имя проекта этого репозитория. |
| **World-A** | Термин в репозитории для развёртывания в настоящем, физически собираемом (vs. лор хронологий). |
| **Zero-click** | Конечный пользователь не открывает Arduino IDE и не компилирует код. |
