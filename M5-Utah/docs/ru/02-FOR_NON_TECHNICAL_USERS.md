# Руководство M5-Utah для нетехнических пользователей

Вам **не** нужно программировать, паять или открывать Arduino IDE. Если вы умеете подключить USB-кабель и дважды щёлкнуть по программе (или выполнить одну команду, которую дал друг), вы сможете пользоваться этой системой.

---

## Что вы получаете

**M5-Utah** превращает маленький гаджет M5Stack в разные полезные устройства:

- **Контроллер ступенчатых площадок** для танцевальных или спортивных игр
- **Цветную демонстрацию на экране** (симулятор волн)
- **Низкочастотный генератор** для экспериментов с катушкой
- **Демо звуковых волн** с двумя выходами
- **Демо мотора, управляемого жестами**
- **Настольную панель**, реагирующую на взмахи руки

Вы покупаете оборудование один раз, прошиваете один раз, а затем **переключаете режимы** в любой момент, выбирая имя из списка.

## Что купить (стартовые комплекты)

Выберите **один** проект для начала. Все используют одно и то же базовое ПО.

### Самый простой старт: Художник волн (только CoreS3)

| Предмет | Примерная роль |
|---------|----------------|
| M5Stack CoreS3 | Основное устройство с экраном |
| USB-C кабель | Обычно идёт в комплекте |

### Ступенчатые площадки: Mnemonic DDR

| Предмет | Кол-во |
|---------|--------|
| M5Stack Core2 | 1 |
| M5Stack PbHub Unit | 1 |
| M5Stack FSR Unit | 4 |
| Grove-кабели (HY2.0-4P) | 5 |

Смотрите [Каталог артефактов](ARTIFACTS.md) для полного перечня комплектующих.

## Одноразовая настройка (попросите технического друга ИЛИ следуйте точно)

### На вашем компьютере

1. Установите **Python 3** с [python.org](https://www.python.org/downloads/) (на Windows отметьте «Add to PATH»).
2. Откройте терминал в папке `M5-Utah`.
3. Выполните:
   ```
   py -3 -m pip install -r requirements.txt
   ```
4. Если вы получили готовый `m5_integrated_kernel.bin`, он уже должен быть в `M5-Utah/payloads/`. Если нет, технический друг должен собрать его (см. [Техническое руководство](03-FOR_TECHNICAL_USERS.md)).

### На M5Stack (только в первый раз)

1. Подключите M5Stack к ПК через USB-C.
2. Выполните:
   ```
   py -3 run_omni_flash.py
   ```
3. Дождитесь **SUCCESS**. Устройство теперь пустой «приёмник».

**Прошивка нужна только один раз**, если только вы не получили новую плату или крупное обновление прошивки.

## Ежедневное использование (каждый раз, когда нужен новый режим устройства)

1. Подключите USB-C.
2. Выполните:
   ```
   py -3 run_studio.py
   ```
3. Вы увидите нумерованный список, например:
   ```
   [0] Cellular_Regenesis_Chamber.flux.json  (Med-Bed / cores3)
   [1] Holographic_Printing_Press_V5.flux.json  ...
   ...
   ```
4. Введите номер и нажмите Enter.
5. M5Stack перезагрузится в этом режиме. Готово.

### Быстрый путь (если вам дали имя)

```
py -3 run_studio.py --artifact mnemonic_ddr_infinity
```

### Список режимов без подключения

```
py -3 run_studio.py --list
```

## Физическая сборка (без пайки)

Все модули M5Stack используют **Grove-кабели** — цветные разъёмы, которые защёлкиваются.

**Пример — ступенчатые площадки:**

1. Подключите **PbHub** к **Port A** (красный) на Core2.
2. Подключите каждый **FSR** к каналам PbHub **CH0, CH1, CH2, CH3**.
3. Положите каждый FSR под напольную пластину или картонную «зону шага».

**Пример — звуковое демо Med-Bed:**

1. Подключите **Unit-DAC** к Port A на CoreS3.
2. Подключите **Unit-Relay** к Port B.
3. Подключите небольшие динамики или излучатели к винтовым клеммам (помощь взрослого).

Схемы и названия портов: [Каталог артефактов](ARTIFACTS.md).

## Как понять, что всё работает

| Режим устройства | Вы должны увидеть… |
|------------------|-------------------|
| Художник волн | Цвета движутся на экране |
| Память шагов | Число увеличивается, когда вы наступаете на площадки |
| Жужжащая коробка | Статус на экране AtomS3; катушка управляется через MOSFET (используйте осциллограф или светодиод на катушке, если не уверены) |
| Демо Med-Bed | Сообщения в serial; звук от излучателей, если подключены |
| Ручной принтер | Число высоты Z увеличивается, когда вы проводите рукой вниз перед датчиком жестов |
| Стол командира | Экран показывает ACTIVE или HALT, когда вы взмахиваете над датчиком ToF |

Если ничего не происходит: см. **Устранение неполадок** ниже.

## Устранение неполадок

| Проблема | Попробуйте это |
|----------|----------------|
| «No M5Stack detected» | Другой USB-кабель; другой USB-порт; установите драйвер CP210x или CH340 (найдите в Google название платы + «USB driver») |
| Прошивка не удалась | Удерживайте кнопку **BOOT** при подключении USB, затем повторите `run_omni_flash.py` |
| Неверный режим после инъекции | Отключите, подключите снова, запустите `run_studio.py` с правильным номером |
| Ступенчатые площадки не работают | Проверьте, что Grove-кабель полностью защёлкнут; PbHub на Port A |
| Пустой экран | Перепрошейте ядро; убедитесь, что собрали/прошили для правильной платы (Core2 vs CoreS3 vs AtomS3) |

## Чем это НЕ является

Ясность помогает всем:

- **Не** медицинское устройство. «Med-Bed» — это **демо аудиочастот**.
- **Не** настоящий голографический принтер. Это **демо жестов + мотор + реле**.
- **Не** бесконечная память компьютера. Режим шагов **записывает события наступания**.
- **Не** доказанная «психотронная» технология. На GPIO выводятся **известные частоты** (7.83 Hz, 40 Hz).

**История и названия** из творческого архива UFW. **Поведение оборудования** — обычная электроника, которую можно проверить глазами и ушами.

Подробнее: [Для скептиков](05-FOR_SKEPTICS.md)
