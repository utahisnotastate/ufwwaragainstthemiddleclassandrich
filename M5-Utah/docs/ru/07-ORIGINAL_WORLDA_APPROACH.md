# Оригинальный подход World-A (до M5Stack)

До **M5-Utah** репозиторий UFW был организован как **плоский архив из 27 проектов**. Этот документ описывает ту оригинальную структуру, чтобы вы могли сравнить её с путём миграции на M5.

---

## Форма репозитория (оригинал)

```
ufwwaragainstthemiddleclassandrich/
├── README.md
├── The_Zero_Point_GPU_Emulator/
│   ├── The_Zero_Point_GPU_Emulator_BLUEPRINT.json
│   ├── The_Zero_Point_GPU_Emulator_MANUAL.md
│   ├── The_Zero_Point_GPU_Emulator_SCIENCE.md
│   ├── Reality_Engine.cpp          ← stub, not compilable
│   └── The_Zero_Point_GPU_Emulator_LANDING.html
├── Mnemonic_DDR_Infinity/
│   ├── Mnemonic_DDR_Infinity_BLUEPRINT.json
│   ├── Mnemonic_DDR_Infinity_BOM.csv
│   ├── AKASHIC_RAM.cpp
│   └── ...
├── ... (25 more projects, same pattern)
└── (no M5-Utah/, no build system)
```

Каждый проект обычно включал:

| Тип файла | Назначение |
|-----------|------------|
| `*_BLUEPRINT.json` | Граф компонентов / дерево геометрии |
| `*_SCIENCE.md` | Нарратив валидации, уравнения, mermaid |
| `*_MANUAL.md` | Инструкции по установке и эксплуатации |
| `*_3D.json` | Метаданные сцены |
| `*_LANDING.html` | Статическая промо-страница |
| `*.cpp` / `*.py` | Концептуальный код с **вымышленными import'ами** |

Не было **ни** `requirements.txt`, PlatformIO, ни единого инструмента прошивки.

## Как предполагалось собирать (оригинальная спецификация)

Брифы Batch 1–2 (до миграции M5) описывали **ручные World-A** установки:

### Zero Point GPU
- **Путь ПО:** Компиляция `Reality_Engine.cpp` против vacuum/GPU библиотеки на **CUDA-класс ПК**.
- **Мануал говорит:** NVIDIA GPU, 16 GB RAM, GCC, CUDA Toolkit.
- **Реальность:** `zpe_core.h` не существует в репозитории.

### Mnemonic DDR Infinity
- **Путь оборудования:** Форм-фактор планки DDR5 ИЛИ пьезо-стomp диски на **Arduino**.
- **Проблема:** Самодельное ограничение напряжения (Zener, pull-down), шум макета.
- **BOM CSV:** Реальные детали (Kingston DDR, Murata caps) смешаны с вымышленным «quantum cache».

### Psychotronic Amplifier Array
- **Путь оборудования:** Ручная пайка высокоусилительных транзисторов, caduceus coil, кварцевый резонатор.
- **Проблема:** RF-шум («photon quenching») без тщательного экранирования.
- **Документы:** `Psychotronic_Amplifier_Array_SCIENCE.md` (confidence 0.94) — нарратив, не прошивка.

### Cellular Regenesis Chamber
- **Путь оборудования:** Открытые ОУ, самодельные катушки Tesla, фазово-сопряжённое зеркало на макете.
- **Код:** `CHRONO_HEAL_KERNEL.cpp` → `#include <phase_conjugation.h>` (отсутствует).
- **Также:** `Telomere_Restore.cpp`, геометрия pod в OpenSCAD.

### Holographic Printing Press V5
- **Путь оборудования:** Реверс-инжиниринг **SLA 3D-принтера** через **Raspberry Pi GPIO**.
- **ПО:** `Matter_Compiler.py` → `scalar_physics`, `consciousness_interface` (отсутствуют).
- **Реальная инженерия:** `Holographic Printing Press Design MD.md` ссылается на дизайн в стиле LDGraphy.

### UFW Tactical Command Table
- **Путь оборудования:** «God-Eye» дашборд на мониторе ПК.
- **ПО:** `REALITY_WAR_ROOM.py` → `timeline_analytics`, `psychotronic_radar` (отсутствуют).
- **Ограничение:** Только 2D-экран; нет физических swarm-узлов.

## Оригинальный workflow (типичный пользователь)

1. Клонировать репозиторий, открыть папку проекта.
2. Прочитать `*_MANUAL.md` и `*_BLUEPRINT.json`.
3. Попытаться скомпилировать `*.cpp` или запустить `*.py` → **ошибка** на отсутствующих модулях.
4. Опционально собрать **вдохновлённый** макет из BOM / science doc.
5. Прочитать корневой `README.md` для экономического / хронологического нарратива UFW.

**История верификации:** «Usable code» в корневом README относился к **концептуально** пригодным blueprint'ам, а не к одному рабочему бинарнику.

## Оригинал vs M5-Utah (сводка)

| Измерение | Оригинальный World-A | M5-Utah |
|-----------|----------------------|---------|
| **Сборка** | Пайка, провода, клиппинг напряжения | Grove-кабели, винтовые клеммы |
| **Toolchain** | Arduino IDE, PlatformIO на проект, CUDA, Pi | Одно ядро + инъекция манифеста |
| **Статус кода** | Заглушки + лор | Компилируемая прошивка + Python host |
| **Число проектов** | 27 архивов | 6 развёрнутых артефактов (больше планируется) |
| **Навык пользователя** | EE + ПО | Подключить USB, выбрать из списка |
| **Роль blueprint** | Основная спецификация | Связанная родословная в `.flux.json` |
| **Честное демо** | Требовало самостоятельной интерпретации | Документировано в руководствах для учёных / скептиков |
