このドキュメントは、UFW アーカイブにおける**テスト可能なハードウェア動作**と**物語上の物理学的主張**を分離し、6つのデプロイ可能アーティファクトに対する再現可能な測定プロトコルを提供します。

## 主張の分類

### Tier A — 直接測定可能（World-A）

- 115200 ボーで定義されたフレーミングによる UART マニフェストインジェクション
- ESP32-S3 上の FreeRTOS デュアルタスク実行
- PbHub + FSR 分圧回路からの I2C アナログ読み取り
- 7.83 Hz と 40.0 Hz の PWM 矩形波
- リレー位相反転付き I2C DAC 正弦波生成 約 61.8 Hz
- PAJ7620U2 I2C レジスタ読み取りによるジェスチャー割り込み
- VL53L0X 飛行時間距離しきい値
- 2.4 GHz Wi-Fi 無線上の ESP-NOW ブロードキャストフレーム

### Tier B — 公表された物理学への類推（独自の引用チェーンが必要）

- **シューマン共鳴（約 7.83 Hz）:** 地球—電離層系の極低周波電磁空洞モード。ベンチ上の 7.83 Hz **電気オシレーター**は、アンテナ、電界強度、SNR 解析なしにはその地球物理モードへの結合と同等ではない。
- **40 Hz ガンマ同調:** 公表された神経科学文献は 40 Hz 感覚刺激パラダイムを検討; **このデバイスは臨床結果を実証しない**。
- **61.8 Hz 音響干渉:** ビート消去と位相反転は古典音響学; 「Priore 効果」や「位相共役生物学」への対応は**仮説**であり、ここでは実証されていない。
- **2D グリッド上の波動方程式:** `zero_point_gpu.cpp` 内の数値ラプラシアンステンシル — 標準的な有限差分デモであり、真空計算ではない。

### Tier C — コードベースに経験的根拠なし

- 零点エネルギー GPU / Casimir 計算
- アカシック／真空メモリー割り当て
- 細胞老化逆転
- 意図からのホログラフィック物質コンパイル
- サイコトロニックスカラー放送
- タイムライン分析 / 敵意検出

## アーティファクト別プロトコル

### 1. Zero Point GPU Emulator

**仮説（テスト可能）:** Core 0 が2Dスカラー場更新を計算し、Core 1 が UI ループを飢餓状態にせず描画する。

**装置:** CoreS3、USB シリアル、UART TX のオプション論理アナライザ。

**手順:**

1. `Zero_Point_GPU.flux.json` をインジェクト。
2. 115200 で 60 秒間シリアルをログ。
3. 既知の FPS でカメラまたは目視でディスプレイ更新をキャプチャ。
4. オプションでマニフェストから `parameters.grid_size`、`wave_speed`、`zpe_gain` を読み取り、視覚的伝播速度と相関。

**観測可能量:** シリアルのフレームカウンター（`ZPE GPU f=N`）; 安定したディスプレイ更新; ウォッチドッグリセットなし。

**実証されていない:** 真空エネルギー抽出、フォトンハードライト投影。

---

### 2. Mnemonic DDR Infinity

**仮説（テスト可能）:** FSR 圧力がアナログカウントを `strike_threshold` 以下に下げ、デバウンスされたイベントをトリガーする。

**装置:** Core2、PbHub、4× FSR、ハブチャンネルのオプションマルチメータ。

**手順:**

1. マニフェストをインジェクト; `strike_threshold`（デフォルト 1800）を記録。
2. 既知の質量を FSR パッドに適用; シリアル `[DDR] Memory write` イベントをログ。
3. トリガー回数対応用力曲線をプロット。

**観測可能量:** `write_count` の単調増加; ログ内のチャンネル ID。

**実証されていない:** 非局所メモリー、ペタバイト割り当て、時空間ロック。

---

### 3. Psychotronic Amplifier Array

**仮説（テスト可能）:** AtomS3 が MOSFET ゲート GPIO 上に安定した低周波矩形波を出力する。

**装置:** AtomS3、MOSFET Unit、ゲートとコイル端子のオシロスコープ、**電流制限付き外部 PSU**。

**手順:**

1. マニフェストをインジェクト; デフォルト `schumann` → 7.83 Hz。
2. 周期 T ≈ 127.7 ms ± 許容誤差（水晶、`delayMicroseconds` ジッター）を測定。
3. BtnA を押す; 約 40 Hz（T ≈ 25 ms）への切り替えを確認。
4. `duty_percent` パラメータ対デューティサイクルを文書化。

**安全:** 高コイル電流を GPIO 経由で流さない; MOSFET が MCU を分離。

**実証されていない:** サイコトロニック信号検出、心—物質結合、親 SCIENCE.md の arXiv/MDPI リンクはこのファームウェアでは**再現されていない**。

---

### 4. Cellular Regenesis Chamber

**仮説（テスト可能）:** DAC が `carrier_hz` で正弦波を出力; リレー出力は論理的に半周期反転。

**装置:** CoreS3、Unit-DAC、Unit-Relay、2つのトランスデューサーまたは高インピーダンススコーププローブ、オプション SPL メータ。

**手順:**

1. マニフェストをインジェクト（`carrier_hz`: 61.8）。
2. DAC アナログ出力をキャプチャ — f ≈ 61.8 Hz の正弦波を期待。
3. リレーデジタル出力をキャプチャ — 正弦波ゼロクロスに対して 180° 位相関係を期待（リレー遅延内）。
4. 音響経路が設置されている場合、SPL を測定; **聴覚安全レベルを使用**。

**実証されていない:** DNA 再配列、テロメア復元、生物組織におけるエントロピー低減。

---

### 5. Holographic Printing Press V5

**仮説（テスト可能）:** PAJ7620 ジェスチャーコード `0x04` が Z 増分と `uv_pulse_ms` のリレーパルスをトリガーする。

**装置:** Core2、Unit-Gesture、Unit-Relay、リレー接点のスコープ。

**手順:**

1. マニフェストをインジェクト。
2. 固定距離で制御された下スワイプを実行; リレーパルスをカウント。
3. `z_position_steps` がトリガーごとに 800 増加することを確認（ファームウェア定数）。

**実証されていない:** SLA レジン硬化パイプライン、真空応力物質化、意図明瞭度メトリクス。

---

### 6. UFW Tactical Command Table

**仮説（テスト可能）:** `wave_threshold_mm` 未満の VL53L0X 測距がシステム状態を切り替え、ESP-NOW パケットを送出する。

**装置:** CoreS3、Unit-ToF、ESP-NOW スニファーとしての第2 ESP32（オプション）、オプション Wi-Fi スペクトラムアナライザ。

**手順:**

1. マニフェストをインジェクト。
2. 測定距離で手を近づける; HALT/ACTIVE 遷移をログ。
3. スニファーで ESP-NOW フレームをキャプチャ; MAC ブロードキャスト `FF:FF:FF:FF:FF:FF` とペイロード構造体 `WorkerPacket`（`war_room.cpp` 参照）を文書化。

**実証されていない:** 脅威意図分類、タイムラインシミュレーション、FinOps 収益性センシング。

## 親 `*_SCIENCE.md` ファイルとの関係

例: `Psychotronic_Amplifier_Array_SCIENCE.md` はシュレーディンガー形式の方程式と外部引用で信頼度 0.94 を報告。**そのスコアはアーカイブスキーマ内部のもの**であり、ブラインド複製の出力ではない。

推奨解釈:

1. SCIENCE.md を**概念的参考文献と仮説メモ**として使用。
2. M5-Utah ファームウェアを Tier A 測定のみの**装置定義**として使用。
3. 別途事前登録された研究なしに Tier C 主張を Tier A 結果に統合しない。

## 被験者に関する倫理と安全上の注意

- **医療主張なし** — メッドベッドアーティファクトは音響／電子テストベッド。
- 高 SPL での持続的 61.8 Hz または 40 Hz 曝露には**聴覚保護**。
- **コイル実験** — 電流を制限; 誘導負荷への連続 MOSFET スイッチングは火災リスク。
- **ESP-NOW / Wi-Fi** — 消費者デバイス限度内の RF 曝露; 地域規制を文書化。
