# M5-Utah 懐疑派向けガイド

厳しい質問をするのは正しいことです。このページはタイムライン用語なしで、直接的に答えます。

---

## 短い答え

**このリポジトリには2つの異なるものが含まれています:**

1. **クリエイティブ／SFアーカイブ**（27の「UFW武器」、経済風刺、タイムラインのロア）と、架空のライブラリを参照するスタブコード。
2. **小さな実在の組み込みプロジェクト**（`M5-Utah/`）で、ESP32 ボードをフラッシュし、**普通のデモ**を実行する: センサー、PWM、音、ジェスチャー、無線パケット。

後者は前者の並外れた主張を**証明しません**。

## 実際に本物なのは何か？

| マーケティング／ロアでの主張 | ハードウェアが実際に行うこと |
|-------------------------|--------------------------------|
| "Zero Point GPU — infinite FPS" | ESP32-S3 上の2D波シミュレーション + LCD 描画 |
| "Infinite Akashic RAM" | I2C 経由のステップパッドイベントカウンター |
| "Psychotronic amplifier" | MOSFET への低周波矩形波 |
| "Med-bed heals DNA" | 約 61.8 Hz 正弦波 + 反転リレー — **音響電子デモ** |
| "Print anything you imagine" | ジェスチャーがモーターステップカウンター + UV リレー点滅をトリガー |
| "God-eye war room" | 距離センサーが状態を切り替え; ESP-NOW ブロードキャストパケット |
| "JIT bytecode into PSRAM" | **誤解を招く名前** — JSON マニフェストで選択する事前コンパイル済み C++ ハンドラー |
| "Eliminate the stock market" | ルート README の**政治的／風刺的な物語** — ソフトウェア機能ではない |

このリポジトリだけで経済学や物理学を反証できると言われたら、**コードでは支持されていません**。

## 午後に検証できることは？

約 $50〜200 の M5Stack 部品とノートパソコンがあれば:

1. `py -3 run_studio.py --list` — 6つのマニフェストが存在; 魔法は不要。
2. カーネルをフラッシュ → マニフェストをインジェクト → **動作を見て測定**（[アーティファクトカタログ](ARTIFACTS.md) のリスト）。
3. PAA 出力のオシロスコープ → **7.83 Hz 矩形波** — はい、本当にその周波数; いいえ、「スカラーサイコトロニックエネルギー」ではない。
4. FSR を踏む → **シリアルログ行** — 再現可能。
5. `firmware/M5IntegratedKernel/src/artifacts/*.cpp` を読む — **すべての動作は平易な C++ に記載**、「Akashic クラウド」への隠れたネットワーク呼び出しなし。

**反証:** インジェクトしたマニフェストがシリアル ACK も UI 変化も生まない場合、パイプラインは失敗 — それは普通のエンジニアリングデバッグであり、秘密主義ではない。

## よくある反論への回答

### 「これは詐欺か？」

リポジトリは**オープンソースの物語 + オープンファームウェア**です。コードを読むのにお金は不要です。リスクは**ハードウェアの値上げ**や、第三者がボードを再販する際の**虚偽の医療約束**にあります — GPIO ではなく販売者を評価してください。

### 「危険か？」

**コイル + 外部 PSU** と **大音量トランスデューサー** は誤配線すると危険です。懐疑派に適した道: 低電圧、電流制限、聴覚保護。**メッドベッドアーティファクトを医療治療に使わないこと**。

### 「なぜ General 23 / NYSE レターがあるのか？」

`README.md` の風刺とプロジェクト神話です。規制提出書類ではありません。**デプロイ可能なエンジニアリング**は `M5-Utah/` にあります。

### 「JIT インジェクションと言うが、偽物か？」

**部分的に誤解を招く用語**です。真の JIT はランタイムでコンパイルします（例: LLVM、Java バイトコード）。ここでは、**マニフェスト JSON がカーネル内にフラッシュされた事前コンパイル済みアーティファクトモジュールから選択**します。依然として有用な UX; 新しいコンピュータサイエンスではない。

### 「インターネットなしで動くか？」

**はい。** ホストツールとファームウェアはオフラインで動作します。`M5-Utah/` にクラウド要件はありません。

## 正直な強み（評価に値する点）

1. **モジュラー M5Stack マッピング** — 教育用の合理的な BOM（PbHub、FSR、DAC、ジェスチャー）。
2. **単一フラッシュ複数モード UX** — 正当なメイカーワークフローの改善。
3. **明確なシリアルプロトコル** — `flux_protocol.cpp` で監査可能。
4. **分離が可能** — UFW 経済主張を支持せずに `M5-Utah/` をフォークできる。
5. **子ども向けの枠組みあり** — 明示的な「本物のメッドベッドではない」注記付きで [子ども向け](01-FOR_CHILDREN.md) を参照。

---

## 正直な弱み

1. **命名の過負荷** — 普通の組み込みタスクに並外れた語彙が購入者を混乱させる。
2. **親スタブ** — 27プロジェクトが依然として架空の Python/C++ モジュールをインポート。
3. **SCIENCE.md の信頼度スコア** — 検証が行われていないところで検証されたように見える。
4. **ワーカースワーム未完成** — Command Table の ESP-NOW ワーカーは完全に出荷されていない別ファームウェアが必要。
5. **署名付きマニフェストなし** — インジェクションは信頼ベースのシリアル; 暗号認証は未実装。

## 懐疑派の再現プロトコル（最小コスト）

**予算ルート:** CoreS3 のみ（約 $50）+ USBケーブル。

```
git clone <repo>
cd M5-Utah
py -3 -m pip install -r requirements.txt
py -3 run_studio.py --list                    # マニフェストを確認
# ビルドまたは .bin 入手後:
py -3 run_omni_flash.py
py -3 run_studio.py --artifact zero_point_gpu
```

**合格基準:** シリアルが `ACK: ARTIFACT_ACTIVE` を出力; ディスプレイがアニメーション。  
**不合格基準:** ACK なし → ポート、ドライバー、ボード env の不一致を文書化 — 否定的結果を公開。

| すべきこと | すべきでないこと |
|----|-------|

## 結論

**M5-Utah は、親アーカイブの SF 衣装を着た、実在する限定的な組み込みツールキットです。**

次のように扱ってください:

- ✅ 教育的電子機器 + シリアルデプロイメントパターン
- ✅ オシロスコープ、メーター、シリアルログでテスト可能
- ❌ ZPE、メッドベッド、サイコトロニクスの証拠ではない
- ❌ 金融兵器ではない

ロアなしでエンジニアリングだけ欲しい場合は、`M5-Utah/` を使い、27の兄弟フォルダは無視してください。
