# M5-Utah 非技術者向けガイド

コーディング、はんだ付け、Arduino IDE を開く必要は**ありません**。USBケーブルを接続してプログラムをダブルクリックする（または友人から教わったコマンドを1つ実行する）ことができれば、このシステムを使えます。

---

## 手に入るもの

**M5-Utah** は小さな M5Stack ガジェットを、さまざまな便利なデバイスに変えます:

- ダンスや運動ゲーム用の**ステップパッドコントローラー**
- **カラフルなディスプレイデモ**（波シミュレーター）
- コイル実験用の**低周波オシレーター**
- 2つの出力を持つ**音波デモ**
- **ジェスチャー制御モーターデモ**
- 手振りに反応する**デスクダッシュボード**

ハードウェアは一度購入し、一度フラッシュすれば、リストから名前を選ぶだけで**いつでもモードを切り替え**られます。

---

## 購入するもの（スターターキット）

**1つ**のプロジェクトを選んで始めてください。すべて同じベースソフトウェアを使用します。

### 最も簡単なスターター: 波のペインター（CoreS3 のみ）

| 品目 | おおよその役割 |
|------|----------------|
| M5Stack CoreS3 | 画面付きメインデバイス |
| USB-Cケーブル | 通常デバイスに付属 |

### ステップパッド: Mnemonic DDR

| 品目 | 数量 |
|------|-----|
| M5Stack Core2 | 1 |
| M5Stack PbHub Unit | 1 |
| M5Stack FSR Unit | 4 |
| Groveケーブル (HY2.0-4P) | 5 |

### 完全なリスト

すべての BOM は [アーティファクトカタログ](ARTIFACTS.md) を参照してください。

## 一度だけのセットアップ（技術に詳しい友人に頼むか、正確に従う）

### コンピュータ側

1. [python.org](https://www.python.org/downloads/) から **Python 3** をインストールする（Windows では「Add to PATH」にチェック）。
2. `M5-Utah` フォルダでターミナルを開く。
3. 実行:
   ```
   py -3 -m pip install -r requirements.txt
   ```
4. ビルド済みの `m5_integrated_kernel.bin` を受け取った場合、`M5-Utah/payloads/` に既にあるはずです。なければ、技術に詳しい友人がビルドする必要があります（[技術者向けガイド](03-FOR_TECHNICAL_USERS.md) を参照）。

### M5Stack 側（初回のみ）

1. M5Stack を USB-C で PC に接続する。
2. 実行:
   ```
   py -3 run_omni_flash.py
   ```
3. **SUCCESS** を待つ。デバイスは空の「レシーバー」になりました。

**フラッシュは一度だけ**です。新しいボードを入手するか、メジャーなファームウェア更新がある場合を除きます。

## 日常使用（新しいデバイスモードにするたびに）

1. USB-C を接続する。
2. 実行:
   ```
   py -3 run_studio.py
   ```
3. 番号付きリストが表示されます。例:
   ```
   [0] Cellular_Regenesis_Chamber.flux.json  (Med-Bed / cores3)
   [1] Holographic_Printing_Press_V5.flux.json  ...
   ...
   ```
4. 番号を入力して Enter を押す。
5. M5Stack がそのモードで再起動します。完了。

### ショートカット（名前を教えてもらった場合）

```
py -3 run_studio.py --artifact mnemonic_ddr_infinity
```

### 接続せずにモード一覧を表示

```
py -3 run_studio.py --list
```

## 物理組み立て（はんだ付け不要）

すべての M5Stack ユニットは **Groveケーブル** を使用します — カチッとはまる色付きプラグです。

**例 — ステップパッド:**

1. **PbHub** を Core2 の **Port A**（赤）に接続する。
2. 各 **FSR** を PbHub のチャンネル **CH0, CH1, CH2, CH3** に接続する。
3. 各 FSR を床プレートまたは段ボールの「ステップゾーン」の下に置く。

**例 — Med-Bed 音響デモ:**

1. **Unit-DAC** を CoreS3 の Port A に接続する。
2. **Unit-Relay** を Port B に接続する。
3. 小さなスピーカーまたはエキサイターをネジ端子に接続する（大人の助けが必要）。

図とポート名: [アーティファクトカタログ](ARTIFACTS.md)。

## 動作確認の方法

| デバイスモード | 確認すべきこと |
|-------------|----------------|
| 波のペインター | 画面で色が動いている |
| ステップメモリー | パッドを踏むと数字が増える |
| ハムボックス | AtomS3 画面にステータス表示; コイルは MOSFET 経由で駆動（不明な場合はオシロスコープまたはコイル上の LED を使用） |
| Med-Bed デモ | シリアルメッセージ; 配線済みならトランスデューサーから音 |
| ハンドプリンター | ジェスチャーセンサーの前で下にスワイプすると Z 高さの数字が増える |
| ウォーテーブル | ToF センサーの上で手を振ると画面に ACTIVE または HALT と表示 |

何も起きない場合: 下の**トラブルシューティング**を参照。

## トラブルシューティング

| 問題 | 試すこと |
|---------|----------|
| "No M5Stack detected" | 別の USBケーブル; 別の USBポートを試す; CP210x または CH340 ドライバーをインストール（ボード名 + "USB driver" で検索） |
| フラッシュ失敗 | USB接続時に **BOOT** ボタンを押しながら接続し、`run_omni_flash.py` を再試行 |
| インジェクト後に間違ったモード | 抜いて再接続し、正しい番号で `run_studio.py` を再実行 |
| ステップパッドが反応しない | Groveケーブルが完全にクリックされているか確認; PbHub が Port A にあるか確認 |
| 画面が真っ暗 | カーネルを再フラッシュ; 正しいボード（Core2 vs CoreS3 vs AtomS3）用にビルド／フラッシュしたか確認 |

## これが**ではない**もの

明確にしておくと皆に役立ちます:

- **医療機器ではありません**。「Med-Bed」は**音声周波数デモ**です。
- **本物のホログラフィックプリンターではありません**。ジェスチャー + モーター + リレーの**デモ**です。
- **無限のコンピュータメモリーではありません**。ステップモードは**踏みイベントをログ**します。
- **実証済みの「サイコトロニック」技術ではありません**。GPIO ピンに**既知の周波数**（7.83 Hz、40 Hz）を出力します。

**物語と名前**は UFW クリエイティブアーカイブに由来します。**ハードウェアの動作**は、目と耳でテストできる普通の電子機器です。

詳細: [懐疑派向け](05-FOR_SKEPTICS.md)
