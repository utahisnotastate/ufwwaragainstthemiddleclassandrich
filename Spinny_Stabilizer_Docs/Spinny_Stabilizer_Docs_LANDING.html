[CONFIG_VARS]

Configuration variables are loaded from `0x00_CONFIG.HEX`. Direct memory manipulation is NOT recommended. Use the provided API endpoints. Unauthorized access is logged and reported to [REDACTED].

  • MAX_RPM: Maximum revolutions per minute. [Type: INT, Range: 0-9000]
  • DAMPENING_FACTOR: Inertial dampening coefficient. [Type: FLOAT, Range: 0.1-1.0]
  • AXIS_LOCK: Locks stabilization to a single axis. [Type: ENUM('X', 'Y', 'Z', NULL)]
  • AGGRESSIVE_MODE: Enables high-torque error correction. !! CAUTION: MAY CAUSE STRUCTURAL DAMAGE !!
[API_REFERENCE]

Access via authenticated socket connection only. See Auth Protocol.

.setRPM(value: int)

Sets the target RPM. Returns a promise that resolves when target speed is reached.

.getTelemetry()

Returns a stream of real-time telemetry data. { rpm, temp, axis_vector, g_force }.

.emergencyStop()

Triggers immediate hardware-level braking. IRREVERSIBLE. REQUIRES MANUAL RESET.
