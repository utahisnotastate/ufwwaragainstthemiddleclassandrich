Introduction
------------

The Oculus Universal Viewer is a powerful tool for visualizing and interacting with 3D models, scenes, and data. This manual will guide you through the process of installing, configuring, and using the viewer.

System Requirements
-------------------

* **Operating System:** Windows 10 or later (64-bit)
* **Processor:** Intel Core i5 or equivalent
* **Memory:** 8 GB RAM or more
* **Graphics Card:** NVIDIA GeForce GTX 1060 or AMD Radeon RX 580
* **Display:** High-resolution display with support for HDR

Installation
------------

1. Download the Oculus Universal Viewer installer from our website.
2. Run the installer and follow the prompts to install the viewer.
3. Once installed, launch the viewer by double-clicking on its icon.

Configuration
-------------

### Setting up the viewer

1. Launch the viewer and select "File" > "Open" to load a 3D model or scene.
2. Configure the display settings as needed (see below).

### Configuring the display settings

* **Resolution:** Set the resolution to match your display's native resolution.
* **Aspect Ratio:** Set the aspect ratio to match your display's native aspect ratio.
* **Field of View:** Adjust the field of view to suit your needs.

### Customizing the user interface

* **Toolbar:** Customize the toolbar by adding or removing buttons as needed.
* **Menu Bar:** Customize the menu bar by adding or removing menus as needed.

Using the Viewer
-----------------

### Navigating the scene

1. Use the mouse to rotate, pan, and zoom in on objects.
2. Use the keyboard shortcuts (listed below) to navigate more efficiently.

### Interacting with objects

* **Selection:** Select an object by clicking on it.
* **Manipulation:** Manipulate an object's position, rotation, or scale using the tools provided.

### Viewing metadata

1. Click on an object to view its metadata.
2. Use the "Metadata" menu to customize the display of metadata.

Keyboard Shortcuts
-----------------

| Shortcut | Action |
| --- | --- |
| `Ctrl + R` | Rotate camera |
| `Ctrl + P` | Pan camera |
| `Ctrl + Z` | Zoom in/out |
| `F1-F12` | Toggle toolbars |

Troubleshooting
--------------

* **Graphics issues:** Check that your graphics card drivers are up-to-date.
* **Crashes:** Check the system logs for error messages and report them to our support team.

Note: This manual is a basic guide and may not cover all features and functionality of The Oculus Universal Viewer. For more information, please refer to our online documentation or contact our support team.
